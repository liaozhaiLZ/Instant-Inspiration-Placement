# 灵感速记 · 手机版 v1.2.1

桌面版的手机适配版本。三样东西：

| 文件 | 说明 |
| --- | --- |
| `灵感速记.apk` | **已经打好的安卓安装包**（353 KB，已签名，版本 1.2.1 / versionCode 121），传到手机点一下就能装 |
| `灵感速记-手机版.html` | **单文件 App**，不装 apk 也能用：传到手机用浏览器打开，完全离线 |
| `Android工程\` | 完整的安卓工程（WebView 外壳 + 同一份页面 + 一键构建脚本），用来重新打包 `.apk` |

## 〇、直接装 apk（最快）

1. 把 `灵感速记.apk` 传到手机（微信文件传输助手 / QQ / 数据线 / 网盘都行）。
2. 在手机上点开它 → 允许「安装未知来源应用」→ 安装。
3. 桌面上会出现「灵感速记」图标（就是你给的那张图），点开即用，数据写在手机真实的 `灵感库` 文件夹里。

## 一、马上就能用：把网页版塞进手机

1. 把 `灵感速记-手机版.html` 传到手机（微信「文件传输助手」、QQ、数据线、网盘都行）。
2. 用 **Chrome / Edge / 三星浏览器** 打开这个文件（微信里点「用其他应用打开」→ 选浏览器）。
3. 浏览器菜单 → **「添加到主屏幕」**，桌面上就会出现带应用图标的入口，点开是全屏的，和 App 一样。

> 注意：不要用微信内置浏览器打开，它不支持添加到主屏幕。

### 和桌面版一样的地方

- 打开就是四选一：**新建灵感 / 查看灵感 / 管理灵感 / 设置**
- 新建页顶部菜单：**打开文件 / 新建文件 / 更改底色**
- 新建页有一排**随机标签胶囊**（点一下把 `#标签` 写进正文，再点取消，右侧「换一批」重抽）
- 新建页有**列表工具条**：`• 无序 / 1. 有序 / → 缩进 / ← 取消缩进`，作用于光标行或选中行
- 查看、管理两个列表都标注**最后修改时间**（刚刚 / N 分钟前 / 今天 15:04 / 10-22 09:15）
- 每条灵感都是一个 `.txt`，文件名同样是 `20261022-1240 标题.txt`
- 设置页有**苦命文学**，可以增删改挂件台词（v1.0 起）
- 首页卡片下方那行小字会**随机轮播**问候与写灵感的话（49 条，7 秒换一条，切换回首页也会换）
- 首页右下角有**挂件**（v1.1 起）：按屏宽等比缩放、点击压扁回弹并冒气泡 3 秒、连点随机播台词、可拖动、可换图、可在设置里关闭；**长按挂件**左上角会出现一个朝 -135° 的直角三角形把手，拖它就能拉大拉小（56–300px，大小会记住）
- 深色 / 浅色 / 跟随系统，圆角毛玻璃卡片，强调色可换
- **返回键**先回上一页，只有在首页连按两次才退出（第二次会给提示）
- 首页卡片**点下去会放大一点并变淡**，像按在玻璃上
- **设置 → 壁纸**：从相册选一张图，自动铺满整屏；开了壁纸会暂时隐藏底色选项，随时可清掉
- 新建页写完标题**第一个字**，标签胶囊就换成和这个词相关的词条（词条库 150 个，2–5 字）
- 点首页那句问候语：滚筒转一次显示当前**日期与时间**；短时间内再点，开始轮播彩蛋句子；全部播完后再点会退出程序，下次启动标语变成「学乖了吧，下次别玩了」
- 首页有一整行更扁的**作者的话**入口（彩虹渐变色、部分字会轻轻抖），点进去是居中排的七行文字
- 那句问候语的彩蛋**不会一直挂着**：12 秒没动，或者切到别的页面再回来，标语会自动恢复成当前时段该有的问候，点击数也一起清零
- 管理页底部有**＋ 引入灵感**：从手机里一次挑几个 txt，直接复制进灵感库（文件名沿用「保存时间 + 标题」的规则）
- 按住挂件**约 0.5 秒**（与拖出缩放把手同一个时机）会冒出一句：如果生活把我揍扁，那我就扁扁地离开………
- 作者的话页面故意留了一大块空白：**停留 5 秒**，空白处会慢慢浮出「你怎么还没看完……」「怎么有人能这么闲……」（第二句再晚 1.5 秒）

### 手机版的不同之处

| 桌面版 | 手机版 |
| --- | --- |
| 全局快捷键 `Ctrl+Alt+Space` 呼出 | 手机没有全局热键，改用**桌面图标**一键直达 |
| 托盘常驻后台 | 网页版关掉浏览器就退出；存进浏览器本地存储，**重开还在** |
| 文件保存到 `D:\灵感即时记录\灵感库` | 网页版存在浏览器本地存储里；`.apk` 版存在手机真实的 `灵感库` 文件夹 |
| 开机自启 | 不适用（安卓不需要） |

**写到一半切走也不会丢**：输入时会自动存草稿，下次打开会提示「已恢复上次未保存的草稿」。

## 二、打成 APK：`Android工程\`

工程结构（标准 Android 结构，用 Android Studio 直接打开也行）：

```
Android工程\
├─ settings.gradle / build.gradle / gradle.properties
├─ build-apk.ps1                       ← 不用 Gradle 的一键构建脚本
└─ app\
   ├─ build.gradle
   └─ src\main\
      ├─ AndroidManifest.xml
      ├─ java\com\lingan\quicknote\MainActivity.java
      ├─ assets\index.html             ← 就是手机版网页
      ├─ assets\icon.png
      └─ res\mipmap-*\ic_launcher.png  ← 用你给的那张图标，已生成 5 个尺寸
```

`MainActivity` 只做三件事：装一个 WebView、把 `assets/index.html` 加载进来、通过 `LinganNative` 这个 JS 桥接提供真实文件读写：

| JS 桥方法 | 作用 |
| --- | --- |
| `listNotes()` | 返回 JSON：文件名 / 标题 / 修改时间 / 大小 |
| `readNote(name)` | 读一条 |
| `saveNote(name, content)` | 写一条（同名即覆盖） |
| `renameNote(old, new)` | 重命名（保留文件名开头的时间） |
| `deleteNote(name)` | 删除 |
| `shareNote(name)` | 调系统分享面板（发微信、存备忘录、发邮件都行） |
| `exportAll()` | 把所有灵感汇总成一个 txt 分享出去 |
| `notesDir()` | 返回灵感库真实路径 |

文件落地位置：`Android/data/com.lingan.quicknote/files/灵感库/*.txt`（卸载 App 会一起删掉，重要内容请用「导出全部」备份）。

### 构建（两种方式任选）

**A. Android Studio（最省事）**

1. 安装 Android Studio，首次启动让它自动装 SDK 34。
2. `File → Open` 选择 `Android工程` 目录。
3. 等 Gradle 同步完，菜单 `Build → Build Bundle(s)/APK(s) → Build APK(s)`。
4. APK 在 `app\build\outputs\apk\debug\app-debug.apk`。

**B. 只用命令行（不需要 Android Studio 的界面，也不需要 Gradle）**

需要：JDK 17 + Android SDK（`platforms\android-34`、`build-tools\34.x`）。
然后在 PowerShell 里：

```powershell
cd "D:\灵感即时记录\手机版\Android工程"
.\build-apk.ps1 -Sdk "C:\Users\你\AppData\Local\Android\Sdk"
```

脚本会依次做：`aapt2 compile` → `aapt2 link`（含 R.java）→ `javac` → `d8` → 合并 `classes.dex` → `zipalign` → 自动生成 `debug.keystore` → `apksigner` 签名 → 校验，最后把 `灵感速记.apk` 输出到 **`手机版\灵感速记.apk`**。

> **几个已经踩过的坑，脚本会自动绕开/提示**
> 1. `aapt2` / `zipalign` / `d8` 这些原生工具**不支持中文路径**。工程目录含中文时脚本会自动把工程复制到临时英文目录编译，再把 apk 拷回来；如果 **SDK 本身**在中文路径下，脚本会直接提示你换路径（工具链必须放英文目录）。
> 2. 脚本必须保存为 **UTF-8 with BOM**，否则 PowerShell 5.1 读中文会乱码、语法都过不了（本仓库里的已经是 BOM）。
> 3. 签名钥匙放在 `Android工程\` 下（`debug` + `.keystore`），每次构建复用同一把；想换签名就删掉它再构建（换了签名后手机上要先卸载旧版才能装新版）。
> 4. JDK 只装了没进 PATH 时，先设 `$env:JAVA_HOME = "C:\...\jdk-17"`（指向含 `bin\javac.exe` 的那层），脚本会自己找 `javac` / `keytool`。
> 5. **工具链不要放在 `%TEMP%` 这类临时目录里**。某些受限环境（例如带沙箱的自动化会话）下，从临时目录启动的 `aapt2` / `javac` / `keytool` 会写不出文件：`aapt2` 报 `error: 数据无效。 (13)`，`javac` 报「写入 xxx.class 时出错：拒绝访问」。把 JDK 和 SDK 复制到普通英文目录（如 `D:\android_tools\`）再跑即可，脚本本身不用改。

装到手机：把 apk 传过去点安装，首次会提示「允许安装未知来源应用」，允许即可。

## 苦命文学（v1.0 新增）

设置页多了「苦命文学」入口，进去能看到挂件会播的全部台词，点一句就能改：

- **保存这句** / **新增一句** / **删除这句**，至少保留一句；
- 台词存在浏览器本地存储 `lingan.poems.v1`（apk 版同样走 WebView 的 localStorage）；
- 首页挂件在桌面版才有，手机端只是把这份台词库留好，方便以后同步。

## 与桌面版 1.0 的差异

桌面版 1.0 的「首页挂件」（可拖动的贴纸 + 今天写了 N 条 + 点击压扁回弹 + 连点随机台词 + 右键换图 + 设置里开关）没有搬到手机端：手机屏幕空间小，挂件会挡住卡片，而且手机端的「今天写了 N 条」已经显示在首页标题下方。手机端保留了标签胶囊、列表工具条，v1.0 又补上了苦命文学页，版本号与桌面版对齐为 1.0。

## 挂件（v1.1 新增）

手机端首页右下角现在也有和桌面版一样的贴纸挂件：

- 尺寸用 `width: clamp(76px, 24vw, 132px)` 跟着屏宽等比缩放，小屏不挡卡片、大屏也不会过大；
- 点一下：先像橡皮鸭一样压扁再回弹，同时冒出一句话，3 秒后淡出；
- 4 秒内连点：从「苦命文学」的台词里随机挑一句播放（没连点就是「今天你写了 N 条灵感」）；
- 按住拖动：位置记在配置里，换页面、重开都不丢，并会自动夹在屏幕内；
- 设置页「挂件」：可以整体关掉、从相册换图（自动压到 512px 内）、恢复默认贴纸。

## 与桌面版 1.1 的差异

桌面版的挂件还支持右键换图和托盘常驻、全局热键呼出；手机端没有桌面/托盘概念，所以挂件换成「设置里换图 + 可拖动」，热键换成桌面图标直达，其余（点击压扁回弹、气泡 3 秒、连点随机台词、今天写了 N 条）与桌面版一致。
